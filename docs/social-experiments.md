# Our social tests

The one place that tracks: **what are we trying to learn, what did we change, which posts
are we comparing, and which one won.**

Metricool is the real home of the posts. This file just wraps a test around them and
records what we learn.

## Three simple rules

1. **If a post isn't in Metricool, it isn't real.** Every test below points to a real
   Metricool post by its ID number. No post in Metricool, no test.
2. **Change only ONE thing at a time.** Keep everything else the same and reuse wording
   we've already posted. That way, if a post does better, we know *what* made the difference
   instead of guessing.
3. **Write down which one won,** so the next decision is based on real numbers.

## The parts of a post (what we can change or keep the same)

- **Hook** — the line on screen that stops the scroll
- **Caption** — the words under the post, with hashtags and the link
- **Video** — what's on screen: a data slideshow, pretty b-roll, **your face**, or you talking
- **Sound** — the trending audio (you add this in the app)
- **Format** — reel, carousel, text-on-a-clip, slideshow
- **Where** — Instagram, TikTok, Pinterest
- **When** — the time of day it posts

A test changes **one** of these and keeps the rest identical.

## Starting a new test later

1. Name it and say what you're trying to learn.
2. Pick the ONE thing you're changing; keep everything else the same.
3. Make the posts in Metricool and write their ID numbers here.
4. When they've run, write down which won and what you'll do about it.
