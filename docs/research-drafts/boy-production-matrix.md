# Chanel Boy — production matrix

*Archivist-sourced 2026-07-12 (Fashionphile / Baghunter / Rebag / SACLÀB / Garde Robe). Drives
the Boy selector via production_option (style 424). Same rules as the Classic Flap matrix:
options = produced, not listed; produced-but-unlisted stays selectable + hedged; grey-out =
never produced. Raw rows banked in `seasonal-archive/chanel.jsonl` (Boy rows). Introduced 2011.*

## Sizes (cm approximate; Chanel publishes no official spec)
| Size | ~cm | Status |
|---|---|---|
| Small | 20 | Current |
| Medium ("Old Medium") | 25 | Current |
| New Medium | 28 | Current, most common on the market |
| Large | 30 | Produced, scarce |
| XL | ~38 | **Discontinued** (produced 2013-2014 only) |
| Mini | seasonal | Seasonal size, not the permanent run |

Old vs New Medium are two REAL sizes (New is roomier, extra pockets). Boy WOC / Messenger /
Clutch / Top-Handle / North-South / Belt Bag are separate SUB-STYLES, not sizes.

## Materials
- **Permanent:** Calfskin (launch leather, plain/glazed), Lambskin, Caviar.
- **Seasonal:** Patent, Tweed, Velvet, Sequin, Shearling, Metallic, Iridescent, PVC, Exotic (python/galuchat).

## Construction
- **Permanent:** Diamond (default) AND Chevron (both standard, same tier). Chevron is NOT contamination.
- **Seasonal:** Plain/smooth, woven, embossed, braided.

## Hardware (a real Boy axis)
- **Permanent:** Ruthenium/antiqued (the Boy's signature tone), Aged gold, Gold, Silver.
- **Seasonal/sought:** So Black (black-on-black), rainbow, plexiglass.

## Colours
- **Permanent families:** Black (anchor, ruthenium or antique-gold), Beige, White, Red, Navy.
- **Seasonal:** SAME "no official Chanel colour names" regime as the Flap. Identity = style code +
  season code; shade names are reseller/descriptive. Sourced season-coded examples (descriptive,
  not official): 15C metallic "Golden CC"; 16C iridescent purple; 17C/"Cuba" sequin white/blue/red.

## Contamination gate (the tell = the lock/plate/chain)
Genuine Boy: **rectangular push-lock** (press, not twist) over a **perforated "lego" CC plate**,
a **rectangular border** around the flap, on an **extra-wide flat chain**. Exclude: Classic Flap
(CC turn-lock, thin woven chain), Coco Handle (top handle + turn-lock), Gabrielle (mixed double
chain, no push-lock plate), 2.55 Reissue (Mademoiselle tuck-lock).
