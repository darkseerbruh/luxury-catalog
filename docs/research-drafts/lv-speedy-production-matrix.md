# LV Speedy — production matrix

*Archivist-sourced 2026-07-12 (LV.com / PurseBlog / Yoogi's). Drives style 433 via
production_option. LV rule: the PRIMARY axis is CANVAS/MATERIAL; colour only varies inside the
leather lines (Empreinte/Epi) and LV names are OFFICIAL (unlike Chanel). Raw rows in
seasonal-archive/louis-vuitton.jsonl.*

## Sizes: Nano (~16) · 20 · 25 · 30 (default, most popular) · 35 · 40 (all current; 35/40 reduced).
Bandoulière is NOT a size (a strap construction flag). Speedy Soft (2024) is a sub-model.

## Canvas / material (primary axis)
- **Permanent core:** Monogram (default; vachetta trim), Damier Ebene (dark leather trim, no vachetta),
  Damier Azur (vachetta), Monogram Empreinte (leather, the colour-bearing line).
- **Intermittent/seasonal:** Epi (leather, runs), Vernis (patent), Denim, Multicolore/Vernis/exotics/collabs.

## Colour: leather lines ONLY (Empreinte/Epi). Anchor Noir/Black; other names official + seasonal
(Amethyste, Infini, Havane…). Canvas lines take NO colour choice (the print is fixed).

## Construction: Standard vs Bandoulière (adds detachable strap + two-way zip, since 2011).
## Hardware: fixed per line (gold on canvas/Empreinte), NOT a shopper axis. Vachetta trim = display fact.

## Contamination: Speedy = soft barrel body; Alma = structured domed shell. Nano Speedy ≠ Mini HL.
Speedy Bandoulière = the SAME model + strap, not a separate style.

## DATA GAP for a SELECTABLE canvas axis
Listing material is mostly the generic string "Canvas" (~40% of Speedy listings), not the specific
Monogram/Damier, so canvas cannot be reliably SEEDED into variants from listing data without
mislabeling. Selectable canvas needs a material-enrichment pass (classify the specific canvas from
titles/images) first. The production RECORD (this matrix, shown in "Made in") is live now.
